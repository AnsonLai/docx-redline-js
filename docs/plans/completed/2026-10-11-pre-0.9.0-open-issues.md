## Rules for every item

- Current properties via `core/current-properties.js`; paragraph marks via `engine/paragraph-mark-revisions.js`; numbering
  via `services/numbering-allocation.js`; the Reject All verifier stays `enforce`.
- Word behaviour claims need COM evidence (`Document.Revisions.AcceptAll()/RejectAll()`, never `*AllRevisions()`); only the
  differential script directly, never the `word-com-suite.ps1`/`word-com-corpus-suite.ps1` wrappers while other agents run.
- Gates before each commit: focused suites, `npm test`, `check:types`, `test:isolation`, matrix default + one extended
  seed. Final gate (parent): Word synthetic + corpus lanes.
- A "decide not to do" is allowed only with written evidence in the source plan and here (e.g. Word cannot represent it).
